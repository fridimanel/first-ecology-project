Introduction to GitHub and Collaborative Work:
This project was created as part of the practical assignment for the course Free and Open Source Software. Its main objective is to learn the basic principles of GitHub and collaborative work. 
A new public repository named first-ecology-project was created to organize and share project files.
A README file was added to introduce the project, and an additional file was created to present its content. A classmate was invited as a collaborator to participate in the project. This practical activity helps us understand how GitHub repositories work, how files are created and updated, and how students can collaborate and share their work online.
